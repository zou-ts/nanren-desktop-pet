# 男人桌宠 · Man Desktop Pet

一只 Q 版金发男人的 Windows 桌面宠物：半透明、常驻桌面最上层，会待机、招手、跳舞、
吃零食、举铁、扣篮、跳杀、坐着唱歌、抬脚射门，拖着它还会跑步。

> **v1.5 换内核**：整程序从 tkinter 迁到 PySide6（Qt 6.8），拖拽缩放贴边的帧率与
> 透明边缘都是新的量级。包结构也变了：`男人桌宠.exe` + `_internal/` 必须放在一起。

## 下载

到右侧 **[Releases](https://github.com/zou-ts/nanren-desktop-pet/releases)** 下载最新版
`nanren-desktop-pet-vX.Y.zip`（约 350MB）。

## 安装
1. 解压到任意文件夹（建议取名 `男人桌宠`）
2. **`男人桌宠.exe` 与 `_internal` 文件夹必须保持在一起**，不要单独把 exe 拷走
3. 双击 `男人桌宠.exe`；首次启动 3~5 秒（解码动画素材），之后很快
4. 不需要安装 Python 或任何运行库
5. 解压后应有 **4879 个文件 / 约 558MB**；数量差很多就是解压没完成，用 7-Zip 重解一遍

## 首次启动先开功能模块（不然会觉得「功能不全」）

内核有「新装默认纯核心」的策略：刚装上只有核心桌宠能力（动画、拖拽、气泡、菜单、设置、
更新）。**灵动岛、聊天、天气、待办、音乐识别、每日抽签、节日提醒、识屏、语音朗读、
系统工具、跨屏、快速启动** 这 15 个可选模块默认全部不激活，所以菜单里看不到、灵动岛
开了也不显示。

开启路径：右键人物 →「设置」→ 左栏「**功能**」→ 右上「**全部开启**」
（或单独勾需要的模块；「推荐套件」只含天气/待办/抽签/节日/语音/聊天，**不含灵动岛**）
→ 关掉设置 → 右键「退出」→ 重新双击 exe。

页面顶部也写着：勾选**重启后才生效**。勾完模块后再打开「灵动岛」自己的显示开关即可。

## 操作
- 左键单击人物：切换下一条动作
- 长按左键拖动：人物跟着鼠标跑，松手回到待机（带惯性与甩出）
- 拖文件到人物身上：它会「一口闷」并播吃饭动作（不动你的文件）
- 把人物拖到屏幕左右边缘松手：贴边探头
- 右键人物：分组菜单（动作 / 外观 / 开关 / 小工具 / 设置 / 帮助与更新）
- 滚轮：放大缩小（脚底位置不动）
- 退出请走右键「退出」，直接关窗口会留下托盘图标

## 功能
- **动作**：16 段素材，待机 / 跑动 / 点击回应 / 随机表演；拖拽奔跑自动翻转方向
- **桌面互动**：拖文件喂食、贴边探头、召唤分身（互相碰撞弹开）、鼠标穿透、免打扰
- **系统集成**：系统托盘、全局快捷键、开机自启
- **小工具**：待办提醒、天气（Open-Meteo 免 Key）、节日与 24 节气、每日抽签、
  音乐识别与歌词、系统状态、网络信息、游戏帧率
- **对话与识屏**：填任意 OpenAI 兼容接口即可对话；识屏 OCR 全本地（模型随包、不落盘）
- **彩蛋**：右键菜单首行的「男人」点一次弹一张图，点几次叠几张

## 更新
- 右键 →「帮助与更新」→「检查更新」；更新源就是本仓库的 Releases
- 更新检测走 GitHub API，接口不通时回退到 jsdelivr 上的 `update.json`
- 老版本（v1.4 及更早）的自动更新读 `version.json`，内容保持兼容

## 目录结构（解压后）
```
男人桌宠/
  男人桌宠.exe
  使用说明.txt
  _internal/
    assets/characters/q_nanren/   ← 角色素材（webm + 帧序列缓存）
    assets/nanren_shots/          ← 菜单彩蛋图
    ...
```

配置与缓存在 `%APPDATA%\dsh-pet-standalone\`（卸载时删掉该目录即可清干净）。
