# 男人桌宠 · Man Desktop Pet

一只 Q 版金发男人的 Windows 桌面宠物：半透明、常驻桌面最上层，会待机、招手、跳舞、
吃零食、套塑料袋、举铁、扣篮、跳杀，拖着它还会跑步。

## 特点
- 9 个动作 + 拖拽奔跑（跑动方向自动翻转）
- 待机时会随机冒出「碎碎念」气泡
- 支持鼠标滚轮缩放、甩出抛物线飞行与边缘反弹
- **内置自动更新**：启动时自动检查，有新版本一键下载替换并重启

## 系统要求
- 仅支持 Windows（推荐 Win10 / Win11 64 位）
- 无需安装 Python 或任何运行库

## 安装
1. 到右侧 **Releases** 下载最新版附件 `男人桌宠.zip`
2. 把 zip 解压到一个文件夹（例如命名为 `男人桌宠`）
3. **必须保持 exe 与 pets 文件夹在同一个目录**，否则会提示找不到素材
4. 双击 `男人桌宠.exe` 即可召唤

## 操作
- 左键单击人物：切换下一条动作
- 长按左键拖动：人物跟着鼠标跑，松手回到待机
- 右键人物：弹出菜单（任选动作 / **检查更新** / 退出）
- 滚轮：放大缩小（脚底位置不动）

## 更新
程序内置更新器，启动会自动检查；也可右键 → 「检查更新」。
更新源就是本仓库的 `version.json`，每次发布新版 Release 时同步更新即可。
