# 男人桌宠 · Man Desktop Pet

一只 Q 版金发男人的 Windows 桌面宠物：半透明、常驻桌面最上层，会待机、招手、跳舞、
吃零食、套塑料袋、举铁、扣篮、跳杀、坐着唱歌、坐着吃饭、抬脚射门，拖着它还会跑步。

## 特点
- 12 个动作 + 拖拽奔跑（跑动方向自动翻转）
- 待机时会随机冒出「碎碎念」气泡
- 支持鼠标滚轮缩放、甩出抛物线飞行与屏幕边缘反弹
- **内置自动更新**：启动时自动检查，有新版本一键下载替换并重启

## 功能扩展（v1.4 新增）
- **设置窗口**：六页（常规 / 桌宠 / 互动 / 工具 / AI / 关于），改动即时生效
- **分组右键菜单**：动作、外观、七个开关、工具、音乐、AI、帮助与更新
- **系统集成**：系统托盘、全局快捷键、开机自启、鼠标穿透、免打扰
- **桌面互动**：拖文件喂食（不动你的文件）、贴边探头、黄金回旋、多开小肥鱼（互相碰撞弹开）
- **小工具**：待办提醒、天气（Open-Meteo，免 Key）、节日与 24 节气、每日抽签、
  音乐识别与歌词、系统状态、网络信息
- **AI（可选）**：填入 OpenAI 兼容接口即可对话；识屏截图只在内存处理，不落盘

## 系统要求
- 仅支持 Windows（推荐 Win10 / Win11 64 位）
- 无需安装 Python 或任何运行库

## 安装
1. 到右侧 **Releases** 下载最新版附件（形如 `nanren-desktop-pet-v1.4.zip`）
2. 把 zip 解压到一个文件夹（建议命名为 `男人桌宠`）
3. **必须保持 exe 与 pets 文件夹在同一个目录**，否则会提示找不到素材
4. 双击 `男人桌宠.exe` 即可召唤

## 操作
- 左键单击人物：切换下一条动作
- 长按左键拖动：人物跟着鼠标跑，松手回到待机（带惯性与甩出）
- 拖文件到人物身上：它会「一口闷」并播吃饭动作
- 把人物拖到屏幕左右边缘松手：贴边探头偷看
- 右键人物：弹出分组菜单（动作 / 外观 / 开关 / 工具 / 设置 / 检查更新 / 退出）
- 滚轮：放大缩小（脚底位置不动）

## 更新
程序内置更新器，启动会自动检查；也可右键 → 帮助与更新 → 检查更新。
更新源就是本仓库的 `version.json`，每次发布新版 Release 时同步更新即可。
访问不了 GitHub 时可用右键 →「从本地 zip 包更新…」离线升级。
